# Assets Folder

Store all design and media files here.

## Subfolders:

### screenshots/
- App screenshots
- UI previews
- Feature demonstrations
- Bug report screenshots

### mockups/
- UI mockups (Adobe XD, Figma exports)
- Wireframes
- Design prototypes
- Layout sketches

## File formats:
- Images: PNG, JPG
- Design files: FIGMA, XD, SKETCH
- Videos: MP4, AVI

## Usage:
Use these assets for:
- Documentation
- Presentations
- Design reviews
- User guides
- Marketing materials
